# Лабораторная работа №5 · Динамические библиотеки

Вариант 9: производная `cos(x)` и подсчёт простых чисел на отрезке `[A, B]`. Проект написан на C11 для Linux, в том числе WSL.

| Библиотека | Производная | Подсчёт простых |
| --- | --- | --- |
| `libforward.so` | Правая конечная разность | Перебор делителей |
| `libcentral.so` | Центральная конечная разность | Сегментированное решето Эратосфена |

Из корня репозитория выполните:

```sh
make run
```

Цель `run` собирает проект и запускает `runtime`. Для первой программы используй `make run PROGRAM=linked`. Чтобы только собрать обе программы, выполни `make`.

`linked` связывается с первой библиотекой при сборке. `runtime` загружает библиотеки по путям `./build/libforward.so` и `./build/libcentral.so` относительно текущего каталога, поэтому запускайте её из корня репозитория.

При запуске в терминале программа показывает меню. Введите `1` или `2`, нажмите Enter и затем введите два числа по подсказке. В `runtime` команда `0` переключает библиотеку, а `q` завершает программу. Можно также ввести команду с аргументами в одной строке.

| Команда | Действие |
| --- | --- |
| `1 A deltaX` | Вычислить производную в точке `A` (радианы). Шаг конечный и ненулевой. |
| `2 A B` | Подсчитать простые, включая обе границы. Допустимо `1 <= A <= B <= INT_MAX`. |
| `0` | Переключить библиотеку в `runtime`. |
| Ctrl+D | Завершить ввод. |

```sh
printf '1 0 0.5\n2 1 100\n0\n1 0 0.5\n2 1 100\n' | ./build/runtime
readelf -d build/linked
readelf -d build/runtime
```

Для запуска под трассировщиком используй `make strace`. Откроется меню `runtime`, а системные вызовы запишутся в `build/runtime.trace`. Для первой программы используй `make strace PROGRAM=linked`. Её трасса появится в `build/linked.trace`. Повторный запуск перезаписывает файл трассы выбранной программы.

После выхода через `q` посмотреть лог можно командой `less build/runtime.trace`. В приложении Б [отчёта PDF](report/report.pdf) приведены сохранённые трассы обеих программ.

Для `make report` нужны XeLaTeX, пакеты LaTeX для русского языка и шрифты CMU Serif и CMU Typewriter Text (пакет `fonts-cmu` в Ubuntu). С полным набором пакетов шаблона доступна также сборка через `make report LATEX=pdflatex`.
